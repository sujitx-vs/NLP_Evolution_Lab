    On many modern systems, especially Linux and recent Python installations, the default is indeed UTF-8.
    However, on some Windows setups, the default has historically been a Windows-specific code page (such as cp1252 or another locale-specific encoding).
    That's why explicitly specifying encoding="utf-8" is considered good practice—it makes your code behave consistently across different machines.
